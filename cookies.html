Cookie notice

What this site stores on your device. There is no separate control to set, because the house does not place optional cookies.

Last updated November 2026

The footer names this page under cookie settings. There is no settings panel. The house does not set optional cookies, and it does not use a consent service. This note is the record of what the pages actually keep.

What the house sets

The scripts written for this site do not set a cookie. There is no analytics tag and no advertising pixel.

What the browser keeps instead

The pages use the browser’s own storage, which is not a cookie.

  • Local storage holds the bag, under the name cittacico-cart-v1, so the selection survives a refresh. Signing out clears it on that device. A signed-in bag is also saved with the account.
  • Local storage holds the sign-in session, so the account stays open between visits. The sign-in library writes it. The password is not kept there.
  • Session storage lasts only as long as the tab. It remembers that you set aside the invitation to join the house, under the name cittacico-member-prompt-v1, and it keeps the last order summary, under the name cittacico-last-order, so the confirmation page can show it.

Requests that leave the site

Loading a page requests typefaces from Google Fonts and loads the sign-in library from jsDelivr. Using the boutique or an account talks to the house’s Supabase project. Those services receive the request the browser makes. The house does not add a tracker of its own on top of them.

Stripe is not called unless the house has turned payments on. When it has, the card is entered on Stripe’s page, not here. While payments are off, checkout records the order and stops. No card number is asked for on this site.

If you want them gone

Your browser can clear site data for this website, including local storage and session storage. That signs you out on this device and empties the bag on it. It does not close an account, and it does not cancel an order already sent to the house. For that, write to cittacico@gmail.com.

How an account and an order are kept is described in the privacy policy. The terms of use cover the boutique.
